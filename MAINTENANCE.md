# CT Municipal Employment Directory — Maintenance Guide

This document explains how to maintain and update the dataset powering the Streamlit app.

The system has three layers:
1. **Canonical dataset** (municipal JSON)
2. **Link validation + enrichment** (reports/)
3. **Streamlit app** (UI + trust display)

---

## 📦 File Overview

### Core dataset
- `CT_Municipal_Employment_Pages.json`
  - Source of truth for municipalities, URLs, and platform data

### Validation output
- `reports/link_health_report.csv`
- `reports/link_health_report.json`
  - Generated by validator
  - Contains link status, redirects, timestamps, etc.

### Scripts
- `check_urls.py` → validates all links
- `apply_url_check_summary.py` → optional metadata enrichment
- `rediscover_employment_links_v3.py` → finds replacement links
- `merge_rediscovered_into_canonical.py` → safely applies updates

### App
- `ct municipal jobs.py`
  - Loads JSON + validation report
  - Displays trust status and filters

---

## 🔄 Standard Maintenance Workflow

Run this workflow whenever:
- links break
- towns update their websites
- before sharing/selling dataset
- periodically (weekly or monthly)

---

### 1. Run Link Validation

```bash
python check_urls.py CT_Municipal_Employment_Pages.json

This generates:

reports/link_health_report.csv
reports/link_health_report.json

✔ This step is required for:

trust status in the app
identifying broken links
2. Review Validation Results (Quick Check)

Open:

reports/link_health_report.csv

Look for:

validation_status = broken
validation_status = suspicious
unexpected redirects

👉 If everything looks reasonable, continue.

3. (Optional) Rediscover Broken Links
python rediscover_employment_links_v3.py

This attempts to find:

updated employment pages
new application PDFs
4. Run Safe Merge (Test Mode)
python merge_rediscovered_into_canonical.py --out reports/CT_Municipal_Employment_Pages.merged.test.json

This will:

apply only safe updates
skip risky replacements
generate:
reports/merge_report.csv
reports/merge_audit.json
5. Review Merge Results

Open:

reports/merge_report.csv

Check:

action_taken = applied
action_taken = manual_review_needed

👉 Confirm:

no good links were downgraded
applied changes make sense
6. Apply Updates to Canonical (Only If Safe)

If everything looks correct:

python merge_rediscovered_into_canonical.py --out CT_Municipal_Employment_Pages.json

⚠️ This overwrites the canonical dataset
Do this only after reviewing test output.

7. Commit and Push
git add .
git commit -m "Update municipal employment links + validation report"
git push

This updates:

dataset
validation report (used by app)
deployed Streamlit app
8. Verify Live App

Open:

https://ct-municipal-employment-directory.streamlit.app/

Check:

statuses show as Verified, Redirected, etc.
not everything is Unverified
filters work correctly
⚠️ Important Rules
Never blindly trust rediscovery
It can find outdated pages
Merge script protects against this, but always review
Do not overwrite working links
Canonical data should be stable
Only replace links that are broken or clearly improved
Validation report must exist
If reports/link_health_report.csv is missing:
app will show everything as Unverified
🛠 Troubleshooting
Everything shows "Unverified"
Check:
reports/link_health_report.csv exists in repo
Streamlit app can load it
Town names match exactly
Weird characters in UI
Ensure:
ct municipal jobs.py is saved as UTF-8
no smart quotes or emoji encoding issues
Merge says "applied" but nothing changes
Re-run test merge
check output JSON
confirm write path is working
Good link replaced by worse link
This is a bug
Do not apply merge
fix merge rules before proceeding
📅 Suggested Schedule
Light use: run monthly
Active use / selling data: run weekly
Before sharing/exporting dataset: always run
